Review notes

  1. Offline pill. Shown in the middle of the top bar only while offline mode is on, so it is never there for online use. Green, with a laptop glyph and the word "Offline". Tooltip: "Offline mode is on: translations happen on this computer. Click to manage languages." Clicking opens the Offline languages window. It goes away the moment offline mode is turned off in Settings, or when the Pro licence lapses.
  2. Translate button. A small green dot on the arrow while offline mode is on. The tooltip changes from "Translate" to "Translate offline".
  3. Result caption. Under a result that was translated offline: "Translated on this device, English to Spanish". It is cleared as soon as the result is cleared or an online translation replaces it. History entries keep a small offline marker too.
  4. Both colours follow the light and dark themes (try the toolbar). Green is used rather than the accent so the pill does not look like a button the user must press.
