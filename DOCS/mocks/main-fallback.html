Review notes

  1. Option A. When Google answers 429 and the language pair is installed for offline use, Glate translates on this device straight away, with no dialog. The usual offline caption under the result says why: "Google is limiting requests, so this was translated on this device, English to Spanish". Offline mode in Settings stays off, so the next translation tries Google again. History marks the entry as offline, like any offline result.
  2. Option B. The 429 error gets a "Translate on this device" button. Nothing happens until the user clicks it.
  3. When there is no fallback (both options): the source is Auto Detect (offline needs a known source language), the pair is not installed, or the user has no Pro licence. Then the 429 error approved on 2026-11-04 shows unchanged. Free users see no hint about offline translation (Pro) in that error.
  4. No waiting period. Google's 429 carries no Retry-After header, so there is no wait time to show. Glate keeps sending a request only when the user asks for one.
