Review notes

  1. When Google answers 429 and the language pair is installed for offline use, Glate translates on this device straight away, with no dialog. The usual offline caption under the result says why: "Google is limiting requests, so this was translated on this device, English to Spanish". Offline mode in Settings stays off, so the next translation tries Google again. History marks the entry as offline, like any offline result.
  2. When there is no fallback: the source is Auto Detect (offline needs a known source language), the pair is not installed, or the user has no Pro licence. Then the 429 error approved on 2026-11-04 shows unchanged. Free users see no hint about offline translation (Pro) in that error.
  3. No waiting period. Google's 429 carries no Retry-After header, so there is no wait time to show. Glate keeps sending a request only when the user asks for one.
