Settings: Quick Translate shortcut

The App Settings group in Settings, in each state the shortcut can be in. Only the Quick Translate row and the line under it change; Voice and On close stay as they are.

1. X11 or Windows: Glate holds the keys

App Settings
Quick TranslateCtrl+Shift+Space
Select text in any app, then press the keys.
VoiceFemale (Default)

2. X11 or Windows: another app has the keys

App Settings
Quick TranslateCtrl+Shift+Space
Another app uses these keys. Press other keys in the field.
VoiceFemale (Default)

3. Wayland: the desktop holds the key (KDE Plasma, GNOME 48+)

App Settings
Quick TranslateCtrl+Shift+SpaceChange...
Your desktop manages this shortcut. Select text in any app, then press the keys.
VoiceFemale (Default)

4. Wayland: accepted, but no key chosen yet (KDE)

App Settings
Quick TranslateNo key yetChoose keys...
Your desktop asks you to choose the keys for Quick Translate.
VoiceFemale (Default)

5. Wayland without a shortcut service (sway, GNOME 46/47)

App Settings
Quick TranslateSet in your desktop
This desktop does not let apps add shortcuts. Add a custom shortcut in its keyboard settings that runs:
glate --quick-translate
VoiceFemale (Default)

6. Wayland: the desktop refused it

App Settings
Quick TranslateNot allowedTry again
The desktop did not allow the shortcut.
VoiceFemale (Default)

Review notes

  1. Wayland gets Quick Translate. Today the switch is greyed out there ("unavailable"). The key now goes through the desktop's shortcut service (the xdg-desktop-portal, as in Omnidict and Paraphrase), which works in the snap and the Flatpak too.
  2. On Wayland the desktop owns the key. The key field shows what the desktop bound and is read only; Change... opens the desktop's own shortcut dialog. The first time, the desktop asks once to allow the shortcut, suggesting Glate's key.
  3. X11 and Windows keep today's key field. A line under it says when another app already has the keys.
  4. Where the desktop has no shortcut service, a custom desktop shortcut can run glate --quick-translate, which translates the selected text in the running Glate.
  5. On Wayland the selected text is read once Glate's window is in front (the desktop only gives it to the active window); if nothing is selected, the clipboard is used. The xclip program is no longer needed.
